# Material para subir

Carpeta temporal para el material original del cliente. Claude lo convierte (WebP, MP4 + WebM) y lo
ubica en `assets/`; esta carpeta se borra antes de pasar a `main`.

- `asesores/`: fotos de cada asesor. Nombra cada archivo con el nombre de la persona (por ejemplo `valentina-medina.jpg`).
- `videos/`: videos (saludos de asesores, tomas de los proyectos). Nombra el archivo con lo que muestra.

GitHub acepta archivos de hasta 25 MB por la web; si un video pesa más, compártelo por Google Drive.
